# about-me

프로젝트 관련 문서 및 로컬 데모 페이지 링크입니다. 아래 파일을 클릭해 내용을 확인하세요.

- 프로젝트 기획서: [project_proposal.md](project_proposal.md)
- MVP 요약: [mvp_summary.md](mvp_summary.md)
- 구현 가이드: [implementation_guide.md](implementation_guide.md)
- 사업계획서(문서): [business_plan.md](business_plan.md)
- 사업계획서(웹): [business_plan_site.html](business_plan_site.html)
- 상세 요구사항: [detailed_requirements.md](detailed_requirements.md)
- 데모 시작 페이지: [index.html](index.html)

로컬에서 웹 데모를 확인하려면 아래 명령으로 간단한 HTTP 서버를 실행하세요:

```bash
cd about-me
python -m http.server 8000
# 브라우저에서 http://localhost:8000/ 에 접속
```
